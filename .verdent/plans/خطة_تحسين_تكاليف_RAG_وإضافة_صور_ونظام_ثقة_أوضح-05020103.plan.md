# الهدف

تحسين نظام RAG السياحي لعرض تكاليف أكثر واقعية وشمولية، إضافة صور موثقة لمواقع إضافية مهمة في عمان، وتحسين علامات الثقة والمراجعة للبيانات.

# نطاق العمل المقترح

## 1. تحسين نموذج التكاليف في بيانات RAG

### الملفات المستهدفة

- `types/tourism.ts`
- `lib/rag/tourismData.ts`
- `lib/rag/format.ts`

### التغيير المقترح

تحويل `ticketCostOmr` من رقم بسيط إلى كائن غني:

```ts
interface VisitorCost {
  entryFee: {
    omani?: number | null;      // null = مجاني
    tourist?: number | null;
    notes?: string;             // "مجاني للعمانيين، 1 ريال للسياح"
  };
  estimatedExperienceCost: {
    min: number;
    max: number;
    currency: "OMR";
    includes: string[];         // ["موقف سيارات", "مرشد", "مشروبات"]
  };
  notes?: {
    en: string;
    ar: string;
  };
}
```

### السلوك المطلوب

- إذا كان الدخول مجانياً للجميع: `entryFee: { omani: 0, tourist: 0 }`
- إذا كان مجانياً للعمانيين فقط: `entryFee: { omani: 0, tourist: 1, notes: "..." }`
- إذا كانت التكلفة غير مؤكدة: `entryFee: null` مع `notes: "يحتاج مراجعة"`
- `estimatedExperienceCost` يظهر تقديراً شاملاً للتجربة الكاملة (موقف + طعام + تسوق)

## 2. تحسين نظام الثقة والمراجعة

### الملفات المستهدفة

- `types/tourism.ts`
- `lib/rag/tourismData.ts`
- `components/RecommendationCard.tsx`
- `components/RecommendationDetails.tsx`

### التغيير المقترح

استبدال `needsImageReview: boolean` بنظام أوضح:

```ts
interface DataVerification {
  status: "verified" | "pending_review" | "unverified";
  confidence: "high" | "medium" | "low";
  lastUpdated: string;          // ISO date
  dataQuality: {
    hasImages: boolean;
    imageCount: number;
    hasVerifiedCosts: boolean;
    hasOpeningHours: boolean;
    hasAccessibilityInfo: boolean;
  };
}
```

### عرض في الواجهة

- **verified**: علامة خضراء "بيانات موثقة"
- **pending_review**: علامة صفراء "قيد المراجعة - قد تتغير التفاصيل"
- **unverified**: علامة حمراء "يحتاج تحقق - يرجى التأكد محلياً"

## 4. تحسين عرض البطاقات في الواجهة

### الملفات المستهدفة

- `components/RecommendationCard.tsx`
- `components/RecommendationDetails.tsx`

### التحسينات المقترحة

#### في البطاقة الرئيسية:
- عرض `estimatedExperienceCost` كـ "تكلفة تقريبية للشخص"
- إضافة أيقونة توضح حالة التوثيق (✓ موثق / ⚠ قيد المراجعة)

#### في قسم التفاصيل الموسع:
- **تفاصيل التكلفة**:
  - رسوم الدخول (عماني / سائح)
  - تكلفة التجربة الشاملة (min-max)
  - ما يشمله المبلغ
  - ملاحظات خاصة

- **حالة البيانات**:
  - تاريخ آخر تحديث
  - مستوى الثقة
  - ما إذا كانت الصور موثقة
  - ما إذا كانت التكاليف مؤكدة

## 5. تحديث بيانات التكاليف في data.json

### الملف المستهدف

- `data.json` (القراءة والتحليل)
- `lib/rag/tourismData.ts` (معالجة التكاليف)

### التحليل المطلوب

للمواقع الـ 103:
1. تحديد المواقع التي يُعرف أن دخولها مجاني (معظم الشواطئ، الأودية، الأسواق)
2. تحديد المواقع التي يُعرف أن لها رسوم (القلاع، المتاحف، بعض الكهوف)
3. تحديد المواقع التي تحتاج بحثاً للتأكد

### القيم الافتراضية المقترحة

```ts
const DEFAULT_COSTS: Record<string, Partial<VisitorCost>> = {
  // مجاني للجميع
  "beach|wadi|souq|corniche": {
    entryFee: { omani: 0, tourist: 0, notes: "مجاني للجميع" }
  },
  // مجاني للعمانيين، رمزي للسياح
  "fort|castle|museum": {
    entryFee: { omani: 0, tourist: 1, notes: "مجاني للعمانيين، 1 ريال للسياح" }
  },
  // يحتاج تأكيد
  "cave|reserve|adventure": {
    entryFee: null,
    notes: { en: "Entry fee varies, please check locally", ar: "تختلف الرسوم، يرجى التحقق محلياً" }
  }
};
```
